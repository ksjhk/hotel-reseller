# 卡世界酒店代理分销 API

面向酒店代理商、分销平台、私域电商、SaaS 服务商和开发者。代理预充值后，通过 API 密钥接入全国实时酒店房源，把酒店产品放进自己的网站、小程序、公众号或分销系统，自主定价并销售赚差价。

本仓库提供酒店代理介绍、对接文档和 DeepSeek Harness 插件，不附带商城源码或其他业务资料。

## 代理怎么做这门生意

1. 注册卡世界开放平台账号，创建代理密钥并预充值。
2. 查询酒店、房型和实时结算价，将房源接入自己的销售渠道。
3. 根据目标客群、渠道成本和售后成本自主制定销售价。
4. 客户在你的渠道下单后，你的服务端调用酒店代理 API 创建订单。
5. 平台按代理结算价扣除预充值余额，并返回酒店确认结果。
6. 销售价与代理结算价之间的差额构成代理毛收入，实际利润还需扣除支付、营销和售后等成本。

代理掌握自己的客户、售价和销售渠道。卡世界提供酒店货源、订单履约、确认状态查询与失败退款能力。

## 已具备的能力

- 全国实时酒店房源搜索、详情和房型报价。
- 下单前可订检查与重新确认报价。
- 代理密钥、预充值余额和 API 自动下单。
- 酒店确认状态查询，处理中可轮询。
- 确认失败自动退款，便于代理对账和售后。
- 酒店只读查询支持匿名调用；下单、订单查询和余额查询必须签名。

## 适合哪些 B 端业务

- 已有用户和订单渠道，需要增加酒店品类的分销平台。
- 需要统一酒店货源与履约接口的 SaaS 服务商。
- 运营公众号、小程序、社群或企业客户渠道的代理商。
- 希望自建酒店分销系统、掌握定价权的开发团队。

## DeepSeek Harness 插件

插件只适用于 **DeepSeek Harness（DSH）**，普通 DeepSeek 手机 App 和网页聊天版不能安装。保留原仓库地址，纯 JavaScript，无 TypeScript 或构建步骤。

```bash
dsh plugin --profile web add github:ksjhk/hotel-reseller
```

安装后提供 6 个工具：酒店搜索、详情、房型报价、可订检查、订单查询、创建酒店订单。只读查询和可订检查匿名可用；订单工具需要代理自己的密钥：

```bash
export KASHIJIE_APP_KEY='你的 app_key'
export KASHIJIE_APP_SECRET='你的 app_secret'
```

Mock 或自托管接口可通过 `KASHIJIE_HOTEL_API_BASE_URL` 覆盖默认 API 根地址。

自然语言使用示例：

> 查询北京的酒店和房型报价，按代理结算价整理成表。
>
> 下单前先做可订检查并重新报价，等我明确同意后再创建订单。

**创建订单会真实扣除代理预充值余额。** 插件要求下单工具显式传入 `confirm: true`，未确认不会发请求；网络超时先查单，不重复下单。完整字段与签名规则仍见 [酒店代理 API 文档](docs/api.md)。

## 对接流程

```text
代理注册并预充值
→ 搜索酒店与房型报价
→ 在自己的渠道自主定价
→ 下单前执行可订检查
→ 服务端签名创建代理订单
→ 查询酒店确认状态
→ 展示确认结果或退款结果
```

完整接口、字段、签名算法和调用示例见 [酒店代理 API 文档](docs/api.md)。
